# Product Overview

Educational repository for learning structured programming concepts through C#.

## Purpose

Demonstrates the evolution of programming paradigms through a "Turtle vs Crocodile" game implemented in progressively more sophisticated styles:

- Section00-01: Unstructured programming (goto statements, global variables)
- Section02-03: Structured programming (loops, conditionals, static functions)
- Section04-05: Object-oriented programming (SOLID principles, design patterns, clean architecture)

## Target Audience

Developers learning:
- Structured programming fundamentals
- Transition from procedural to OOP
- Clean architecture and design patterns
- C# language features

## Language

Primary documentation and comments are in Japanese (日本語).
